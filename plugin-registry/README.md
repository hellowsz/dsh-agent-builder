# plugin-registry —— 开源插件收集器

定时从公开仓库收集好用、高 star 的 DSH 兼容插件,整理成一份可被搭建助手检索的清单,让"选插件"这一步有货可选。

## 要解决的问题

搭建助手要组合插件,前提是有一个**足够厚、信息足够全**的插件清单。目前 DSH 尚无成熟插件市场,这个收集器就是来补这块的:把散落在各处的可用插件聚合、打分、更新。

## 收集流程(草案)

1. **发现**:按关键词/主题在公开代码仓库检索候选插件,记录来源地址。
2. **筛选**:按 star 数、最近更新时间、是否符合 DSH 插件形态(导出 `apply` 等)过滤。
3. **核验**:确认插件声明的能力、依赖、注入项;标注是否需要密钥、是否有网络副作用。
4. **入库**:写入清单,每条含名称、来源、能力摘要、star、最近更新、可信度标注。
5. **定时更新**:周期性重跑,刷新 star 与更新时间,淘汰失活项。

## 清单条目字段(草案)

- 名称 / 来源地址
- 能力摘要(一句话说清它能干什么)
- star 数 / 最近更新时间
- 依赖与注入项
- 是否需要密钥、是否有外部副作用
- 可信度标注(已核验 / 待核实)

## 注意

- 收集回来的是**第三方代码**,入库不等于可信。默认按"待核实"标注,给搭建助手和用户看清来源,不替用户做信任判断。
- 未经核验的能力名、API 名不编造,查不到就标"待核实"。
