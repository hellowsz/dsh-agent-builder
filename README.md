# dsh-agent-builder

让**纯新手**用对话搭一个能**稳定交付结果**的 agent,不用懂技术。产物是一份 DeepSeek Harness 配置文件(yml),藏在后台;固定后直接在 DeepSeek Harness 里运行,稳定交付内容。

## 它是什么

- 你和一个"搭建助手"聊:要干什么、给它什么输入、想要什么样的结果、什么算合格。
- 搭建助手挑选并组合需要的插件,跑一批真实样例做测试,给你一份**稳定性报告**(跑了多少个样例、通过多少、哪些情况会翻车)。
- 你确认后,它把这套配置**固定下来**(生成 yml,并为这个 agent 生成一套专属验证门禁)。以后运行这个 agent,门禁把关,行为一致。

对纯新手来说,yml 和 DeepSeek Harness 都在后台,你只面对"聊清需求 → 拿到一个稳定干活的 agent"。

## 和可视化编排工具的区别

那类工具的编排层本身带模型的不确定性;这里的产物是**声明式装配**——加载哪些插件、怎么接线,是确定的代码路径,不靠模型临场猜。同一份 yml,装出来的能力骨架每次一样。

需要说清:yml 固定的是**能力骨架**,不是模型每次吐出的**内容**。内容的稳定靠"固化前多样例测试 + 可检验的验收标准 + 每个 agent 专属的验证门禁"来压,这是本项目的核心工作。

## 目录

- `builder/` —— 对话式搭建助手:收敛需求 → 选插件 → 跑样例 → 生成 yml 和专属门禁。
- `plugin-registry/` —— 开源插件生态仓库(规划,后续独立成单独仓库):由定时 agent 自动全网筛选高 star 的 DSH 相关插件入库,清单面向 AI 接入。
- `docs/` —— 定位、稳定性验证机制、插件生态、MVP 边界等设计说明。
