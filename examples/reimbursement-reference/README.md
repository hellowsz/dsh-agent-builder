# mvp-reimbursement —— 报销门禁判据

MVP「报销单据整理助手」的核心:验证门禁的**确定性判据**(①结构 ②规则 ③对照防编造)。这是整个产品最值钱、也最该先立住的部分——判据质量 = 交付稳定性。

④ AI 评审由独立评审 agent 承担,不在本包(本包只做能确定性判定的三层)。

## 结构

```
src/
  schema.ts            报销单结构 + 门禁结果类型（全只读）
  checks/
    structural.ts      ① 结构：格式/字段/类型/范围/类别集合
    rules.ts           ② 规则：税额≤金额、日期不晚于今天、税额占比 sanity
    grounding.ts       ③ 对照：金额/税额/发票号/日期必须在原文找到依据（防编造）
  gate.ts              合三层为一次裁决（跑全并汇总问题，便于失败喂回）
test/
  fixtures.ts          一个好样例 + 6 个坏样例（改金额/编发票号/未来日期/…）
  gate.test.ts         断言：好样例全过、每个坏样例被对应问题码挡下
```

## 跑测试

```
npm install
npm test
```

## 设计要点

- **③ 对照是防编造的核心**:改金额(428→482)、编发票号会被"原文里找不到依据"挡下。取数按数字分词,不会把长发票号误当金额。
- **可重复**:`today` 由外部传入,不依赖真实时钟,检查每次结果一致。
- **不命中即停**:三层全跑、汇总所有问题,失败时能把完整原因喂回 agent 让它改。
- **纯函数 + 只读**:判据只读不改产出。
